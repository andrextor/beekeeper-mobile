8. **Deep link** — `src/app/h/[code].tsx`, resume-after-sign-in in the auth guard.
9. **Release** — `chore(release): 0.5.0`. Check: `pnpm ci:check`.

## How Iván tests it

On a real Android phone with the dev build, local backend (or remote) with the seed:

1. Hive C-01 → "Etiqueta QR" → Compartir PDF → send to yourself on WhatsApp; the label shows "C-01", the QR, `ABCDE-FGHIJ`-style code, "Landak Apiario", no location.
2. Apiary "Vallecito 1" → "Imprimir etiquetas" → PDF with all hives, 3×4 grid. Print one page on paper.
3. Center tab Escanear → point at the printed C-01 → phone vibrates and opens C-01. Repeat **in airplane mode** → same.
4. **With gloves on**: toggle Linterna, open "Escribir código", type the code with an `O` instead of `0` → opens C-01.
5. Scan the QR with the system camera app → Landak opens on C-01.
6. As owner, "Cambiar etiqueta" → "Generar código nuevo" → print → scan the new label → C-01; scan the old one → "Este código no está asignado"; C-01's history shows the label change after M6.
7. Sign in as `reviewer@landak.test` → scan a label of "Apiario Ajeno" (print it from the other account) → "Esta colmena no pertenece a tus apiarios"; "Cambiar etiqueta" is not visible.
8. Scan any random QR (a website) → "Este código no es de Landak Apiario", nothing opens.
