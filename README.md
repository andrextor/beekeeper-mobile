# beekeeper-mobile

Landak Apiario Android app: offline-first hive management for beekeepers (Expo + React Native + TypeScript).

Backend and API contract: sibling repo `beekeeper` (`../beekeeper/docs/api.md`). Stack decided in `../beekeeper/docs/superpowers/specs/2026-10-25-foundation-design.md` §4.

Status: empty. The Expo scaffold and the field-mode UX spec come in this repo's first plan, after the backend foundation is approved.
